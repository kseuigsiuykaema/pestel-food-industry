# 光翼獣ソレアロン × 陽砕獣テラノクス — 夜の東京

夜の東京（港区）で2体の怪獣が暴れ回る、約64秒の3D映像（音声なし）。
すべてのモデル・テクスチャ・都市・エフェクトは Three.js のコードでプロシージャル生成しています（外部アセットは字幕フォントのみ）。

- 完成映像: `output/kaiju_tokyo_night.mp4`（1920×1080 / 24fps / H.264）
- リアルタイム版: `index.html`（ブラウザで再生。シークバーあり）

## 怪獣

| | 光翼獣 ソレアロン | 陽砕獣 テラノクス |
|---|---|---|
| 体色 | アイボリーの鱗、隙間から橙の光 | 赤い鱗＋黄金の装甲板 |
| 特徴 | 炎の羽根で構成された翼（折り畳むと炎のマント）、太陽冠のような頭部のたてがみ、光輪、胸の太陽コア | 羅針盤状の大光輪、重装甲の肩・脚、ギザギザの背びれ |
| 技 | 口からの太陽光線、飛翔 | 地面を砕く一撃（衝撃波と溶岩の亀裂） |

各個体は1つのスキンメッシュ（約20〜30万ポリゴン）で、次の要素をすべてコード生成しています：

- プログラムで組んだ骨格（背骨・首・顎・尾10節・腕・脚・翼）
- 骨に沿ってロフトした胴体チューブ＋重なり合う鱗のノーマル／ラフネス／発光マップ
- 表面の実際の傾きに沿って配置した数百枚の装甲板、棘、牙、爪、指、炎の羽根
- 頭部のロフト（眉稜・頬・顎の蝶番）、縦長の瞳孔をもつ発光眼、角、冠、光輪
- 二関節IKで足を地面に固定した歩行サイクル。咆哮・叩きつけ・被弾・離陸の各ポーズ

## 都市

- 約1万棟の建物（インスタンシング）。窓のグリッドはシェーダーで生成し、遠景はアンチエイリアス処理
- 倒壊はすべてシェーダー内で時間から計算（傾き・歪み・沈下・停電・窓の炎）
- 東京タワー（トラス構造、ライトアップ、折れて倒れる）、東京スカイツリー、首都高、車の流れ、街灯、
  スクランブル交差点、ネオン看板、緊急警報を流す街頭ビジョン、東京湾、遠景の夜景
- 雲の層（ソレアロンが降下時に穴を開ける）、月、煙に霞む空

## 決定論的レンダリング

すべてのパーティクル（煙・炎・粉塵・火花・残り火・瓦礫）は初期化時に生成時刻付きで作られ、
シェーダーが任意の時刻の状態を解析的に計算します。倒壊イベントは振り付けを事前にサンプリングし、
怪獣の骨の位置を建物と判定して求めています。そのため `renderFrame(t)` は `t` だけで決まる純関数で、
シークもフレーム単位の書き出しも可能です。

## 実行方法

```bash
npm install
npx http-server -p 8080 .          # http://localhost:8080/ でリアルタイム再生
npm run render                     # frames/ に書き出し → output/kaiju_tokyo_night.mp4 にエンコード
node still.mjs /tmp/shot 12,23.5,33 1920 1080   # 静止画を数枚だけ出力
```

レンダリングは `render.mjs`（Playwright＋ヘッドレスChromium→ffmpeg）で行います。
ffmpeg は `imageio-ffmpeg` パッケージ（pip）から取得するか、PATH 上のものを使います。

## ショット構成

1. 空撮：東京タワーとスカイツリー、午後11時47分
2. 雲を割って降下するソレアロン、着地の衝撃波
3. スクランブル交差点：首都高を踏み砕き、ネオンの間を迫るテラノクス
4. 地面を砕く一撃：衝撃波と溶岩の亀裂
5. ソレアロンの咆哮（クローズアップ）
6. 太陽光線が街を薙ぎ、テラノクスの胸に命中
7. 吹き飛ばされたテラノクスが東京タワーに激突、タワーが倒壊
8. 燃える街を回り込むオービットショット：両者の咆哮
9. ソレアロンの飛翔
10. 光輪を背負うテラノクスの後ろ姿と、太陽のように空に浮かぶソレアロン
